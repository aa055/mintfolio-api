# mintfolio-api

Backend for **Mintfolio** — a portfolio management platform for physical precious metals.

This service is the single source of truth for all portfolio data. The frontend in [`mintfolio-web`](https://github.com/aamir/mintfolio-web) authenticates via Supabase Auth, then sends every read/write through this API. The frontend never touches Supabase tables directly.

---

## Stack

| Layer | Choice |
|---|---|
| Framework | FastAPI 0.115 |
| Language | Python 3.11+ |
| ORM | SQLAlchemy 2.0 (async) |
| Migrations | Alembic |
| Validation | Pydantic v2 |
| Database | Supabase Postgres |
| Auth | Verify Supabase JWTs (HS256) |
| HTTP client | httpx |
| Storage | Supabase Storage (signed URLs) |
| Pricing | GoldAPI.io (daily cached) |
| Hosting | Render (web service + cron) |

## Getting started

### 1. Create and activate a virtual environment

```bash
# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# macOS / Linux
python -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements-dev.txt
```

### 3. Configure environment

```bash
cp .env.example .env
# Fill in DATABASE_URL, SUPABASE_*, GOLDAPI_KEY
```

### 4. Run migrations

```bash
alembic upgrade head
```

### 5. Run the dev server

```bash
uvicorn app.main:app --reload --port 8000
```

API docs: <http://localhost:8000/docs>
Health: <http://localhost:8000/health>

## Project layout

```
app/
  main.py              FastAPI app factory + middleware
  config.py            Pydantic settings (reads .env)
  db.py                Async SQLAlchemy engine + session dependency
  deps.py              Auth dependency (verifies Supabase JWT)
  models/              SQLAlchemy ORM models
    base.py            Declarative base + UUID/Timestamp mixins
  schemas/             Pydantic request/response models (to be added)
  routers/             FastAPI route modules
    health.py          GET /health
  services/            Business logic — pricing, valuation, storage (to be added)
  jobs/                Scheduled jobs — daily price fetch (to be added)
alembic/
  env.py               Reads DB URL from app.config
  versions/            Migration files (autogenerated)
tests/
  test_health.py       Sanity check on /health
```

## Common commands

```bash
# Create a new migration after editing models
alembic revision --autogenerate -m "describe the change"

# Apply pending migrations
alembic upgrade head

# Roll back one revision
alembic downgrade -1

# Run tests
pytest

# Lint + format
ruff check .
ruff format .

# Type-check
mypy app
```
